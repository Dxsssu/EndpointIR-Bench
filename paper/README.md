# Papers

本目录收录与 EndpointIR-Bench 相关的论文。

## 论文列表

### SecRespond: Benchmarking AI Agents for Real-World Post-Compromise Incident Response

- 文件：[SecRespond.pdf](./SecRespond.pdf)
- 作者：Lehan Wang, Boli Chen, Ruixue Ding, Pengjun Xie, Jinwei Huang, Zhendong Liu, Shuo Wang, Tao Lei, Xin Ouyang, Xiaomeng Li
- arXiv：[2607.26791](https://arxiv.org/abs/2607.26791)
- 提交日期：2026-07-29
- 简介：SecRespond 是一个面向真实入侵后事件响应流程的 LLM Agent 基准，包含 10 个网络靶场，覆盖 4 类入口、21 项 MITRE ATT&CK 技术和 5 种操作系统，并以细粒度检查点评估入侵调查、风险识别和修复规划能力。

### From Sands to Mansions: Actionable, Customizable and Causality-Preserving Cyberattack Emulation with LLM-powered Symbolic Planning

- 文件：[From-Sands-to-Mansions.pdf](./From-Sands-to-Mansions.pdf)
- 作者：Lingzhi Wang, Zhenyuan Li, Yi Jiang, Zhengkai Wang, Xiangmin Shen, Wei Ruan, Yan Chen
- arXiv：[2407.16928](https://arxiv.org/abs/2407.16928)
- 版本：v4（2026-02-05；首次提交于 2024-07-24）
- 会议：24th International Conference on Applied Cryptography and Network Security（ACNS 2026）
- 简介：论文提出自动化网络攻击仿真系统 Aurora，结合 LLM 与符号规划，将异构攻击工具组织为可执行、可定制且保持步骤间因果关系的攻击链；作者基于 250 份威胁情报报告构建攻击仿真数据，并用于评估三种入侵检测系统。
